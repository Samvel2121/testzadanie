# Development Notes

## Что сделано

- Реализован модуль заметок на Laravel.
- Добавлена авторизация через Laravel Breeze.
- Создана таблица notes с полями id, user_id, title, content, color, is_pinned, created_at, updated_at.
- Реализован CRUD для заметок.
- Добавлена проверка, что пользователь работает только со своими заметками.
- Добавлен поиск по заголовку и тексту.
- Добавлена пагинация.
- Заметки выводятся карточками.
- Реализован выбор цвета заметки.
- Реализовано закрепление заметки через Alpine.js и fetch.
- Добавлена CSRF-защита и валидация через Form Request.
- Добавлена ссылка регистрации на странице входа.
- Добавлен README с инструкцией запуска.

## Что не успел

- Не добавлены автоматические тесты для NotesController.

## Принятые решения

- Использован Laravel, потому что он предоставляет готовые механизмы маршрутизации, авторизации, CSRF-защиты, валидации и безопасной работы с базой данных.
- Использована SQLite, потому что проект тестовый и не требует отдельной настройки MySQL или PostgreSQL.
- Использованы Blade и Alpine.js, чтобы выполнить frontend-часть без сложной SPA-архитектуры.
- Проверка user_id выполняется в контроллере, чтобы пользователь не мог редактировать, удалять или закреплять чужие заметки.
