# Модуль «Заметки»

Тестовое задание: внутренняя система заметок для сотрудников.

## Возможности

- регистрация и авторизация пользователей;
- создание, редактирование и удаление заметок;
- просмотр только своих заметок;
- поиск заметок по заголовку через GET-параметр `q`;
- вывод закреплённых заметок сверху;
- закрепление и открепление заметки без перезагрузки страницы через Alpine.js и fetch;
- выбор цвета заметки;
- пагинация по 20 заметок на страницу;
- CSRF-защита и серверная валидация.

## Технологии

- Laravel;
- Blade;
- Alpine.js;
- Tailwind CSS;
- SQLite.

## Установка и запуск

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate
npm run dev
php artisan serve
```

После запуска приложение будет доступно по адресу, который выведет команда `php artisan serve`.

## Что сделано

Реализован модуль заметок с CRUD-операциями, авторизацией, проверкой принадлежности заметок пользователю, поиском, пагинацией, выбором цвета и закреплением заметок.
